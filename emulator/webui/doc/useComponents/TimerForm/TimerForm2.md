# Prompt: Generate the **TimerForm** Component (Sensors Section)

Create a new component called **TimerForm**, structured as follows:

```
webui/
 ├── js/
 │   └── components/
 │       └── TimerForm/
 │            ├── TimerForm.js
 │            └── TimerForm.func.js
 └── css/
     └── components/
         └── TimerForm.css
```

The component will replace the existing hardcoded timer HTML block inside `SensorsForm.js`.
It must be a self-contained UI element that reads data from the **store**, reacts to **Observer subscriptions**, and navigates using **navigatorManager** — without ever mutating the store directly.

---

## 🧩 Purpose

This component represents the **ON/OFF timer control card** inside the “Sensors” section of the application.
It displays two time values — ON and OFF — and automatically updates them when the store changes.
When the relay mode is set to **Bypass**, the card expands to span six grid columns, and the Relay card hides itself.


   ```
   webui/css/components/ComponentName.css
   ```
3. The CSS file must be manually included in `index.html` with a relative path:

   ```html
   <link rel="stylesheet" href="./css/components/TimerForm.css">
   ```
4. Use **only relative imports** inside JavaScript files.

## ⚙️ Behavior Summary

* **Extends** `Component.js`
* **Subscribes** to store updates:

  * `timers.mode.on`
  * `timers.mode.off`
  * `config.params[22].relayMode`
* **Never writes** directly to the store.
* **Navigates** using `navigatorManager` to `timerEditorPage` when clicking ON or OFF.
* **Constants:**

  * `timerOn = 8`
  * `timerOff = 9`
* **Labels “ON” and “OFF” are fixed strings**, not translated.
* **The component must automatically unsubscribe** on unmount.
* **Uses `i18n.js` only indirectly** through its parent `SensorsForm` for section labels.

## 🧠 Behavior in Detail

### Subscriptions

| Store Path                    | Type    | Purpose                                       |
| ----------------------------- | ------- | --------------------------------------------- |
| `timers.mode.on`              | runtime | Updates the ON timer value (MM:SS).           |
| `timers.mode.off`             | runtime | Updates the OFF timer value (MM:SS).          |
| `config.params[22].relayMode` | config  | Expands the card (span-6) if mode = `Bypass`. |

* Each subscription must be created via `Store.subscribe(path, callback)`.
* Each callback must return an unsubscribe function, collected in an array.
* The component must call `unsubscribe()` for all active listeners in `unmount()`.

## 🧩 Navigation Logic

* When the **ON** block is clicked → navigate to `timerEditorPage` with `{ paramId: 8 }`
* When the **OFF** block is clicked → navigate to `timerEditorPage` with `{ paramId: 9 }`

Example:

```js
navigatorManager.navigate('timerEditorPage', { paramId });
```

## ⚙️ Implementation Overview (`TimerForm.js`)

```js
import Component from "../../core/Component.js";
import Store from "../../core/Store.js";
import navigatorManager from "../../core/navigatorManager.js";
import { TIMER_ON_PARAM_ID, TIMER_OFF_PARAM_ID } from "../../utils/constants.js";
import { formatTime, isBypassMode } from "./TimerForm.func.js";

export default class TimerForm extends Component {
  constructor() {
    super();
    this.el = document.createElement("div");
    this.el.className = "pump-card timer-card";
    this.unsubs = [];
  }

  mount(parent) {
    parent.appendChild(this.el);
    this.render();
    this.cacheDom();
    this.bindEvents();
    this.subscribeToStore();
  }

  render() {
    this.el.innerHTML = `
      <div class="pump-card-icon">
        <img src="assets/icons/icon-timer.png" alt="Timer">
      </div>
      <button class="timer-value-group" data-role="on">
        <div class="timer-label">ON</div>
        <div class="timer-value">00:00</div>
      </button>
      <button class="timer-value-group" data-role="off">
        <div class="timer-label">OFF</div>
        <div class="timer-value">00:00</div>
      </button>
    `;
  }

  cacheDom() {
    this.$on = this.el.querySelector("[data-role='on'] .timer-value");
    this.$off = this.el.querySelector("[data-role='off'] .timer-value");
  }

  bindEvents() {
    this.el.querySelector("[data-role='on']")
      .addEventListener("click", () =>
        navigatorManager.navigate("timerEditorPage", { paramId: TIMER_ON_PARAM_ID })
      );
    this.el.querySelector("[data-role='off']")
      .addEventListener("click", () =>
        navigatorManager.navigate("timerEditorPage", { paramId: TIMER_OFF_PARAM_ID })
      );
  }

  subscribeToStore() {
    this.unsubs.push(Store.subscribe("timers.mode.on", (val) => {
      this.$on.textContent = formatTime(val);
    }));

    this.unsubs.push(Store.subscribe("timers.mode.off", (val) => {
      this.$off.textContent = formatTime(val);
    }));

    this.unsubs.push(Store.subscribe("config.params[22].relayMode", (val) => {
      this.el.classList.toggle("span-6", isBypassMode(val));
    }));
  }

  unmount() {
    this.unsubs.forEach((u) => u && u());
    this.unsubs = [];
  }
}
```

## 🧮 Helper Functions (`TimerForm.func.js`)

```js
export function formatTime(value) {
  if (typeof value === "string" && value.includes(":")) return value;
  const total = parseInt(value) || 0;
  const mm = String(Math.floor(total / 60)).padStart(2, "0");
  const ss = String(total % 60).padStart(2, "0");
  return `${mm}:${ss}`;
}

export function isBypassMode(relayMode) {
  // 0 = Bypass
  return Number(relayMode) === 0;
}
```
